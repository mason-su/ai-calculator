# AI Calculator

A clean, responsive web calculator built with plain HTML, CSS, and JavaScript. This project is the first hands-on exercise in an AI Engineering and AI Agent learning journey, focused on AI-assisted software development.

## Features

- Addition, subtraction, multiplication, and division
- Responsive layout for desktop and mobile screens
- Keyboard support for digits, operators, Enter, Backspace, and Escape
- Clear (`AC`) and backspace controls
- Friendly error handling for invalid input and division by zero

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript (no frameworks or libraries)

## Project Structure

```text
ai-calculator/
├── index.html   # Page structure and calculator UI
├── styles.css   # Layout, theme, and responsive styles
├── script.js    # Calculator logic and input validation
└── README.md    # Project documentation
```

## How to Run

1. Clone this repository:

```bash
git clone https://github.com/mason-su/ai-calculator.git
cd ai-calculator
```

2. Open `index.html` in your browser:
   - Double-click the file, or
   - Drag it into a browser window, or
   - Use the local path:
     `file:///D:/projects/ai-calculator/index.html`

No build step, package manager, or local server is required.

## Quick Test Checklist

- `7 + 3 =` → `10`
- `10 − 4 =` → `6`
- `6 × 5 =` → `30`
- `8 ÷ 2 =` → `4`
- `8 ÷ 0 =` → shows an error message
- Try typing with the keyboard and using `AC` / `⌫`
